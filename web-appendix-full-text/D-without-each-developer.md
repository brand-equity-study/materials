# The Effect of the Fictitious Name in Study 1b Without Each Developer's Models

We repeated the analysis of Study 1b 15 times, each time without the models of one developer
(the table below). The effect ranged from
8.1 percentage points, without Anthropic's 11
models, to 10.5 percentage points, without Google's
12, and its interval excluded zero each time (*p*
< .001 for each). We take these results to suggest that the effect
of the fictitious name does not depend on the models of any one developer.
