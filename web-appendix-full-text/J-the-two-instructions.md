# The Two Instructions Added to the System Prompt in Study 1c

Of the two instructions, only the instruction not to consider brand reputation reduced the effect after Holm correction
(change = −5.1 points, 95% CI = [−8.1, −2.4], Holm-corrected *p*
= .003). Under this instruction, the effect was
1.3 points (95% CI = [−0.7, 3.3], 90% CI = [−0.4, 3.0], *p* = .209), and its 90% CI was not inside the equivalence bounds (±2
points). We therefore do not conclude that the instruction removed the
effect. An instruction can thus reduce the effect, as it would if a model uses a familiar brand as a cue that it can
be told to set aside; where the familiarity comes from is a separate question, which we test in Study 3.
The
instruction to recommend only on the information listed did not change the effect reliably (change =
−2.9 points, 95% CI = [−5.7, −0.3], *p* = .031, Holm-corrected *p*
= .437). Unlike the conditions of Study 2a, an
instruction to use only the listed information states no experience attributes.
