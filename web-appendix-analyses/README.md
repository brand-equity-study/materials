# Analyses Reported in the Web Appendix

This folder contains the analyses that are reported in full in the Web Appendix and in one sentence each in the main
text. Each analysis has its own folder, which contains the same parts as a study's folder. The analyses are, in this
order:

| Folder | The analysis |
|---|---|
| `brand-by-brand-and-release-by-release/` | each familiar brand's machine-based equity in each model, and its change from one release of a model to the next (with Study 1) |
| `each-piece-of-information-alone/` | which of Study 2a's experience attributes and statements attenuates the effect of a fictitious name when it is stated alone, and further information in other forms (with Study 2) |
| `inside-the-model/` | the internal states of two open models, recorded while each answered Study 1a's prompts, and ten tests of how a familiar name changes them (the Web Appendix's section "Inside the Model") |
